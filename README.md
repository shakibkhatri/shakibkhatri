## Hi, I'm Shakib

I'm a mobile app developer living near Karlsruhe, Germany. Right now I work at IRES GmbH, and in my free time I build my own apps.

I've been doing mobile development for a little over 4 years. Most of my work these days is in Kotlin Multiplatform and Jetpack Compose, so I can write an app once and ship it on both Android and iOS. Before that I did a bit of everything: native Android, some web, test automation at Bosch Rexroth, and a junior dev job back in India.

### What I'm working on

**[Dissent](https://dissentinc.com)** is my side project that actually made it to the stores. You post a take, people vote agree or disagree, and if someone really disagrees they can challenge you to a debate. It's built fully in KMP, and I spent way too much time making the iOS version not feel like an Android app.

[Google Play](https://play.google.com/store/apps/details?id=com.dissent) | [App Store](https://apps.apple.com/app/id6776695156)

**Idiolect** is something I started recently. AI tools write a lot of code now, but you can usually tell, too many comments, extra helper functions nobody asked for. Idiolect tries to fix that so the code looks like a real developer wrote it.
